# niko-main

个人网站收藏首页，属于 `niko-archive` 组合站点。

`index.html` 是静态首页入口，保留二次元背景、悬停文字主题、添加网站和自适应分页。轻小说书库默认排在第一张卡片，指向 `/nikowenku-archive/#/library`；第二张是星海余页（StarseaFolio），指向 `/StarseaFolio/`，用于 AI 辅助小说创作。

网站列表和主题选择存储在当前浏览器的 localStorage，不会修改仓库或同步给其他访客。直接双击 `index.html` 不会跳转到远端；浏览器通常会限制 `file://` 页面加载 ES 模块与本地 SVG 图标，因此本地预览请通过 HTTP 静态服务器打开。背景插画目前沿用原 HTML 的远程图片地址。

本地只预览静态页面时，可在本目录用现有 HTTP 静态服务器提供文件，例如已安装 Python 的环境执行 `python -m http.server 8080 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8080/`。HTTP/HTTPS 预览地址不会跳转；本地聊天联调另需下文的同源接口代理，书库和写作入口需要主仓库的路由配置。

静态首页不需要安装依赖或构建，部署时由 Nginx 在根路径提供 `index.html`、`chat.css`、`chat.js`、`chat-settings.js`、`browser-settings.js` 和 `select-menu.js`。首页包含 DeepSeek、ChatGPT 官网入口，顶部“对话”按钮展开时隐藏网站卡片和分页，对话面板占满下方空间；收起后恢复卡片。

`chat-conversations.js` 将当前标签页的消息按会话保存在 sessionStorage，包含各会话的未发送内容和当前选择，并迁移原有单会话记录。聊天区左侧的对话列表默认收起，仅显示开关；展开后按最近活动排列，标题取第一条用户消息。手机上使用覆盖式侧栏，选择会话或点击遮罩后收起；桌面侧栏展开时为内容让出空间。生成期间禁止新建与切换，停止或完成后恢复。会话只保存在本机当前标签页，刷新可恢复，不上传服务器；关闭标签页或清除站点数据可能移除记录。

`ui-motion.js` 和 `motion.css` 提供浏览器原生动画，无额外运行依赖。对话面板向下滑入、卡片和分页向下滑出，收起时反向恢复；连续切换从当前位置衔接，调整窗口会清理过渡并恢复正确布局。按钮、文字、输入框和卡片悬停使用统一过渡，主题菜单和弹窗有进出动画，手机 API 配置面板从底部滑入。首页待机时，卡片以 5.6 秒周期错峰上下浮动 5 像素，背景以 18 秒周期缓慢移动，小配饰以 5.2 秒周期错峰轻摇，猫爪依次明暗变化，无需鼠标悬停或输入焦点。悬停或键盘聚焦时该卡片的浮动与配饰暂停，保留原有悬停反馈；未显示的分页、后台标签页和配置弹窗打开期间暂停对应待机动画，对话展开时暂停背景。系统启用“减少动态效果”时取消位移和过渡。对话流式文本不反复触发入场动画。

`site-icons.js`、`site-icons.svg` 和 `ornaments.css` 提供本地图标与配饰：猫爪、铃铛、蝴蝶结、缎带和裙装用于卡片角落、工具栏、对话空白页和标题，操作保留语义清晰的图标与必要文字。所有图形直接使用图标库原版，不自行绘制或拼接图案；仅调整尺寸、颜色与摆放。主题颜色同步到配饰；装饰不接受点击、不进入辅助技术名称，手机和矮屏减少配饰，尊重减少动态效果设置。图标来自 Phosphor Icons 2.1.1 和 Material Design Icons 7.4.47，许可分别见 `licenses/phosphor-icons-MIT.txt` 与 `licenses/material-design-icons-LICENSE.txt`。所有资源随站点发布，运行时不依赖图标 CDN，也没有新增运行依赖。

卡片右下角有 24 种小配饰，包含魔杖、流星、月亮星星、蝴蝶、花朵、羽毛、皇冠、手柄、耳机、冰淇淋、礼物、剑、兔子、独角兽、魔法帽、樱桃和糖果等原版库图标。新增网站时随机分配一个，与网站资料一起保存在浏览器中，翻页和刷新不重新抽取；旧自定义网站缺少配饰时补齐一次。内置网站保留原有配饰与排版。

`select-menu.js` 为对话配置、API 配置和协议选择提供统一的圆角菜单、主题选中态、勾选标记与进出过渡，同时保留原生 select 作为表单与业务状态来源。支持方向键、Home/End、Enter、Escape、Tab 和文字定位；菜单优先使用 popover 顶层显示，避免聊天面板或手机弹层裁切，不支持时使用 body/dialog 浮层。窗口变化会关闭菜单，生成期间的禁用状态、动态配置列表与程序选择同步到外观。

## 首页对话与 API 配置

需要 Node.js 22+，无第三方运行依赖：`npm test` 运行测试，`npm run start:chat` 启动仅监听 `127.0.0.1:4181` 的转发服务。本地联调时由同一个静态服务器将 `/chat-api/` 代理至该服务；生产安装见 `deploy/install-chat.sh https://你的域名`。

“API 配置”内置 DeepSeek 官方地址 `https://api.deepseek.com/v1` 与 `deepseek-flash`，只需填写 API Key。也可新增最多 11 个自定义配置，填写名称、OpenAI Chat Completions / Claude Messages 协议、HTTPS Base URL、模型 ID 和 Key。兼容网关可提供 `/v1` 前缀或完整的 `/chat/completions`、`/messages` 地址。请求为流式文本，思考内容单独显示并默认收起，不写回对话历史；不会自动重试失败的模型调用。

API Key、配置和当前选择在浏览器端通过 Web Crypto 的 AES-256-GCM 加密后保存在 localStorage（`site-shelf.chat.settings.v1`，v2 加密记录），每次写入使用新的随机 IV。加密密钥是当前浏览器 IndexedDB（`site-shelf.chat.crypto.v1`）内不可导出的 CryptoKey，不上传服务端。保存、切换、删除配置均不发送网络请求。空 Key 保留已有 Key；清除 DeepSeek Key 会恢复默认配置，删除自定义配置会移除其 Key。旧版同源明文配置仅在成功加密后升级；存储权限、解密或写入失败不会回退到明文，也不会覆盖原记录。损坏的配置可由用户确认后重置。

清除站点数据后需重新填写；不同浏览器、HTTP 与 HTTPS 不共享配置。HTTP 升级 HTTPS 后需在新地址重新填写一次，不自动传输旧 Key。对话文字只保存在当前标签页 sessionStorage，思考内容不写回模型上下文。浏览器私密模式可能不保留数据。本地加密保护存储内容，不保证抵御已控制此浏览器、操作系统或同源脚本的攻击。

发送消息时，浏览器解密当前 Key，经 HTTPS 将本次配置和对话临时交给同源 `/chat-api/chat` 转发，再通过 HTTPS 访问供应商，兼容不允许浏览器跨域调用的供应商。服务端不创建、读取或写入密钥库，不记录 Key、请求体或上游错误正文；它仍会在请求内存中接触本次 Key，并非端到端加密。HttpOnly、SameSite=Strict、Secure 的随机 Cookie 仅用于并发限制，不携带 Key。旧配置接口返回刷新提示，不再接受持久保存；旧版服务器保存的 Key 不自动导出，升级后需重新填写，并清理旧 `.vault` 和 `master.key` 文件。生产入口强制 HTTPS；浏览器不支持安全上下文时拒绝保存 Key，不伪装成安全存储。本地回环开发地址可使用浏览器认可的安全上下文。

现有 Nginx 站点可运行 `sudo bash deploy/enable-https.sh 公网IPv4` 配置受信任的 IP 证书。脚本通过 HTTP-01 webroot 校验申请 Let's Encrypt 短期证书，添加 443 监听并仅将首页资源升级到 HTTPS，保留既有书库和写作路径；HTTP 聊天接口拒绝提交。独立 systemd timer 每六小时检查续期，成功续期后校验并重载 Nginx。部署前需放行公网 80/443；不会导出用户浏览器 Key，也不会将其保存到服务端。证书属于服务器 TLS 凭据，与用户的模型 API Key 无关。

聊天转发只接受同源请求，拒绝内网、公网解析混入内网、携带账号或非 HTTPS 的上游地址；DNS 校验结果固定到单次 TLS 连接且不跟随重定向。接口有消息大小、并发与频率限制，停止按钮/断开连接会取消上游请求，单次回复最多 5 分钟。测试使用模拟模型流，不使用真实 API Key 或消耗模型额度。

生产安装脚本创建独立的 `niko-home-chat.service`，添加 `/chat-api/` 的 Nginx 流式代理并禁止访问服务源码目录；保留既有书库和星海余页路由，不重启其后台。书库 Node 服务和 80 端口配置见父仓库 README。
